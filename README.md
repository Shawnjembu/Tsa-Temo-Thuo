# Tsa Temo Thuo

**Team 10 - CSI473 Project**

## Project Overview

Tsa Temo Thuo is a marketplace platform connecting farmers with buyers, enabling seamless agricultural product transactions with robust inventory management and order processing capabilities.

## Project Information

- **Course**: CSI473
- **Team**: Team 10
- **Date**: August 2026

## Core Features

### UC-01: Place Order
The system enables verified buyers to place orders against active product listings with the following capabilities:

- **Stock Reservation**: Orders automatically reserve inventory from available listings
- **Validation**: System validates order quantities against available stock
- **Concurrency Control**: Handles simultaneous orders to prevent overselling
- **Idempotency**: Prevents duplicate orders from network retries

## Functional Requirements

- **FR-05**: Order placement and stock reservation
- **FR-06**: Quantity validation and availability checking
- **FR-07**: Concurrent order handling and duplicate prevention
